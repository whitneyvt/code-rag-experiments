Creates a cloud of sample points inside a box using Poisson-disk sampling, which keeps the points spread out so no two are too close together. The inputs are a spacing radius (or a function that gives the spacing) and the lower and upper corners of the box, plus options like the number of attempts and a random seed. It returns the generated points. In the RBF-FD operator example, this is the first step that makes the points the operator will be built on.
