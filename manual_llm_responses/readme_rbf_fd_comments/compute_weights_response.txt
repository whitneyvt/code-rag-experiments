Builds the local RBF-FD weight row for one stencil so that a weighted sum of the neighbor values approximates the differential operator, such as the Laplacian, at the center point. The inputs are the local point positions and the stencil and operator settings, and it returns the weights for that row, sending interior and boundary points down the right path. In the operator example, this is the per-point weight calculation that fills each row of the global operator.
