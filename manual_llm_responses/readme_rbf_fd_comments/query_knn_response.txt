Finds the k nearest neighbors of each query point using a KD-tree over the domain's points. These neighbors form the small local stencil that RBF-FD uses to estimate a derivative at a point. The inputs are which point set to search, the query points, and how many neighbors k to return; it returns the neighbor indices and their distances. In the operator example, this is how each center's stencil is picked before its weights are built.
